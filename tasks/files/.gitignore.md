# Implementation brief for `.gitignore`

## Required change

Keep a narrow `/data/` ignore as defense against accidentally generated local data, while the valid runtime root defaults outside this repository at `<os.homedir()>/.bansay/data`. The server rejects private runtime paths within Vite-served repository trees. Runtime data includes SQLite, journal/WAL sidecars, temporary recording writes, chunks and completed private classes. Existing `.env*` protection with the exception for `.env.example` stays in place.

An explicit `BANSAY_DATA_DIR` must resolve outside repository/Vite-served roots. Avoid an overly broad pattern that hides source fixtures, SQL migrations or markdown plans. The planned synthetic `src/server/fixtures/classroom-av.webm` is intentional test source and must remain trackable. Name the template brief `env-example.md` because the current `.env*` rule would hide a task file named `.env.example.md`.

This is a surgical configuration edit with no new cleanup command. Keep any preexisting tracked file unchanged unless it is explicitly part of the feature.
